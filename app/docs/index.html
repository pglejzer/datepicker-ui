Modern Date Picker Library

A lightweight, pure JavaScript date picker component based on Material Design. Easy to use, fully customizable, and mobile-ready.

Modal Mode

Click input to open centered modal with backdrop (Material Design)

HTML 

<input 
  id="datepicker-modal-test" 
  placeholder="Select date..." 
/>

JavaScript 

const picker = new DatepickerUI('#datepicker-modal-test', {
  ui: {
    displayMode: 'modal',
    backdrop: true,
    modalLabel: 'Select date'
  },
  behavior: {
    closeOnSelect: false
  }
});
picker.create();

Dropdown Mode (With Icon)

Click icon to open dropdown below input (no backdrop)

calendar_today

<div class="relative">

  />

const picker = new DatepickerUI('#datepicker-dropdown', {

picker.create();

Smart Typing

Type dates manually - supports multiple formats

calendar_today

Try typing: 15/12/2024, 15-12-2024, or 15122024

Supported Formats

  • ✓ dd/mm/yyyy, dd-mm-yyyy, dd.mm.yyyy
  • ✓ mm/dd/yyyy, mm-dd-yyyy, mm.dd.yyyy
  • ✓ yyyy-mm-dd, yyyy/mm/dd, yyyy.mm.dd
  • ✓ Pure digits (ddmmyyyy, ddmmyy)

JavaScript 

const picker = new DatepickerUI('#datepicker-smart', {
  ui: {
    format: 'dd/mm/yyyy',
    displayMode: 'dropdown',
    iconSelector: '#calendar-icon-2'
  }
});
picker.create();

Auto Input Mask

Automatic mask formatting as you type (dd/mm/yyyy)

calendar_today

Start typing digits - mask automatically appears: 1512 → 15/12/____

Features

  • ✓ Auto-inserts slashes as you type
  • ✓ Shows placeholder for remaining digits
  • ✓ Validates date in real-time
  • ✓ Click icon to open calendar picker
  • ✓ Combines typing + visual selection

JavaScript 

const picker = new DatepickerUI('#datepicker-mask', {
  ui: {
    format: 'dd/mm/yyyy',
    displayMode: 'dropdown',
    iconSelector: '#calendar-icon-3',
    maskEnabled: true
  }
});
picker.create();

Range Selection Mode

Select date ranges with touch/mouse support and live preview

Desktop: Click start date → hover to preview → click end date

Mobile: Long-press (250ms) to start → drag to preview → release to confirm

Cancel: Press ESC or click start date again

Features

  • ✓ Touch & mouse support
  • ✓ Long-press detection (250ms)
  • ✓ Live preview while hovering/dragging
  • ✓ ESC to cancel active range
  • ✓ Validates against disabled dates
  • ✓ Works in modal & dropdown modes

JavaScript 

const picker = new DatepickerUI('#datepicker-range', {
  ui: {
    displayMode: 'modal',
    rangeSelection: true
  },
  behavior: {
    closeOnSelect: false
  }
});
picker.create();

picker.on('range:end', (data) => {
  console.log(data.startDate, '→', data.endDate);
});
