# Security Policy

## Supported Versions

Security fixes go to the versions listed below.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

Only the latest minor release of a supported major version receives fixes.

---

## Reporting a Vulnerability

If you find a security problem in **datepicker-ui**, please report it privately.

### How to report

- **Do not open a public GitHub issue**
- Send the report through:
  - GitHub **Security Advisories** ("Report a vulnerability" on the Security tab), or
  - Email: **glejzerpiotr@gmail.com**

### What to include

- A description of the issue
- Steps to reproduce, if possible
- The affected version or versions
- A proof of concept or screenshots, if you have them

### Response timeline

- First response: **within 72 hours**
- Status update: **within 7 days**

If the report is accepted, the fix ships in a patch release and a security advisory may be
published. If it is declined, you get an explanation.

---

Thank you for helping keep **datepicker-ui** secure.
